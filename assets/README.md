# Assets

Figures and release media for the public package.

- `reconstruction-map.svg` — the current hero figure (v0.8): one one-use
  floor, the three published lines (quantum-facing axis, finite-epistemics
  axis, contact-interface line), and the Chapter 8 state/receiver closure
  where the Born frame rule and the triality Kochen-Specker obstruction
  meet. Self-contained (no external fonts or images) and theme-aware.
- `reconstruction-ladder.svg` — the earlier hero figure, kept as the v0.1
  chapter figure: the reconstruction ladder from a finite one-use floor up
  to the binary-Bell quantum boundary, each rung labeled by status and
  scope, alongside the kill-list and the run-it output. Self-contained and
  theme-safe.

New media is added here only when it is rights-clear and tied to a release
document.
