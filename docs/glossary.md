# Glossary

Status: first public glossary.

The terms below are public shorthand. They do not override the claim register
or theorem bank.

| term | meaning in this release |
|---|---|
| admission data | a declared knob, interface, completion, product, parameter, or carrier choice not forced by the current theory |
| aperture | a bounded visible sector or quotient; it exposes some structure and hides the rest |
| carrier | a finite algebraic grammar grown or admitted at a stated scope; not automatically all quantum theory |
| completion | an overlay or horizon object added beyond finite staged content |
| contact | a finite staged difference-relation |
| equalized face | the balanced/uniform intermediate configuration a carrier can exhibit but does not by itself select |
| finite reach | every staged difference in the release is reached by finitely many compositions |
| gluing | the co-reception condition that makes fragments jointly receivable |
| graded defect | a sign/positivity condition checked grade by grade over a finite ladder, used as a pass/fail gate rather than a magnitude |
| held | not public-load-bearing yet |
| no-signaling / monoidal composition | the forced compositional grammar: local registration cannot signal, and composition is symmetric, associative, and unital; which process theory fills that grammar is not forced |
| occasion | the one-use event consumed by composition |
| one-use | primitive compositions consume their occasion and do not reuse it |
| Pell fence | the negative-Pell relation `p^2 - 2q^2 = -1` whose sign decides which side of the Tsirelson value `2*sqrt(2)` a finite rational rung sits on |
| receiver | not a mind or selector; a gluing/co-reception condition |
| recovery | known mathematics or physics reconstructed inside the finite-contact frame |
| shipped | evidence included and runnable in this public repository |
| stageability | whether the floor can stage a given arena or configuration at a scope; staging an arena is weaker than selecting its weights |
| trace class | an equivalence class of serial presentations under the quotient relevant to public counting |
| typicality residual | the named single-case gap left after exchangeable counting concentrates; probability is recovered up to this residual, not beyond it |
| witness | a finite fiber element counted by the admissible measure |
| witness fiber | the finite set of witnesses over a staged event whose cardinalities are the counting weights |
