# Documentation

This directory holds public-facing prose only after extraction and scope
review.

Documents in this directory:

- `finite-contact-theory.md` - extraction plan for the theory spine (the
  intended order of the public account, not the release narrative; the paper is
  the narrative).
- `how-to-read.md` - reader guide for the public package.
- `glossary.md` - public terminology and scope reminders.
- `admissibility-calculus.md` - the public instrument and claim discipline.
- `mathematical-core.md` - the public mathematical spine and scope fences.
- `theorem-bank.md` - theorem index with status, scope, evidence, and residuals.
- `public-claim-register.md` - claims with status labels and evidence links.
- `correction-ledger.md` - corrections, withdrawals, failed probes, and demotions.
- `status-labels.md` - public claim labels and hold semantics.
- `publication-policy.md` - intake, wording, no-hype, and DOI rules.
- `hold-register.md` - reconciliation register for held quantum/carrier material.
- `release-checklist.md` - the reusable release gate every version passes
  before tagging.
- `release-roadmap.md` - the v0.1 DOI-readiness roadmap (historical; the
  reusable gate is `release-checklist.md`).
- `roadmap.md` - remaining hinges and planned releases.

Repository-level governance (versioning, chapters, append-only rules, the
citer's contract) lives in [`../EVOLUTION.md`](../EVOLUTION.md).

Verification evidence posture lives in
`../verification/evidence-manifest.md`.

Release rule: no claim enters this directory without a status label and a link
to its evidence class.
