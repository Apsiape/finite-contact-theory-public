# Assets

Figures and release media for the public package.

- `reconstruction-ladder.svg` — the hero figure: the reconstruction ladder from
  a finite one-use floor up to the binary-Bell quantum boundary, each rung
  labeled by status and scope, alongside the kill-list and the run-it output.
  It is self-contained (no external fonts or images) and theme-safe, so it
  renders identically wherever the README is viewed.

New media is added here only when it is rights-clear and tied to a release
document.
